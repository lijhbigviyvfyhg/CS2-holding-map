# CS2 Holding Map

Template and scripts for building CS2 holding/autopeek training maps from official maps.

Start here:

- [CodexAIGC.README.md](CodexAIGC.README.md): repository overview and command flow.
- [CodexAIGC.GUIDE.make-nuke.md](CodexAIGC.GUIDE.make-nuke.md): step-by-step guide for making a Nuke version when you do not know the local map coordinates yet.

The default example is `examples/CodexAIGC.nuke.config.json`.
